# Ruoyo Demo Library

A complete six-page original Demo PDF, converted by PDFReader into online reading data. It includes text, vector fills, curves and images. No product source code or Unity assets are distributed here.

Source URL: https://kqhkdzyrvq-crypto.github.io/pdfreader-library/sources/ruoyo-vector-demo/source.json

This source uses the experimental 2-draft envelope with PRIX2, PRBK1, PRV1 and PRG1 records. Use the current vector-enabled PDFReader development build. Older SDF readers cannot read this source.

The original Demo content and illustrations were prepared for PDFReader by Ruoyo. This publication is reading data, not a licence to the PDFReader software. Rendering data includes the characters used by the document; no standalone font files are supplied.
